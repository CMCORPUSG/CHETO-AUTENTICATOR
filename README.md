# CHETO-AUTENTICATOR

Aplicación Android personal para generar códigos TOTP/2FA de forma local y segura.

## Objetivo

- Escanear cuentas mediante QR `otpauth://`.
- Registrar cuentas manualmente mediante clave secreta.
- Generar códigos TOTP sin conexión.
- Proteger las cuentas con cifrado local y Android Keystore.
- Bloqueo biométrico/dispositivo.
- Backup cifrado en Google Drive (appDataFolder).
- Programar backup automático cada 24 horas.
- No almacenar secretos, QR, claves TOTP, contraseñas ni backups en GitHub.
