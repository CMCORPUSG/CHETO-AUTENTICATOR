# Contributing

Las contribuciones se realizan mediante fork y Pull Request.

Antes de enviar cambios ejecutar:
.\gradlew.bat testDebugUnitTest lintDebug assembleDebugAndroidTest assembleDebug
git status --short

No publicar secretos TOTP, OTP reales, QR reales, backups .cheto, tokens, contraseñas, keystores, keystore.properties ni client secrets.

Usar únicamente datos ficticios en pruebas y capturas.
