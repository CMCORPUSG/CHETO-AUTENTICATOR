# CHETO Authenticator 1.0.0

Primera release estable del cliente Android nativo.

## Incluye

- TOTP offline.
- QR estándar y migración.
- PIN y biometría.
- Bóveda local cifrada.
- Categorías, favoritos, búsqueda, edición y papelera.
- Perfil local.
- Exportación y restauración .cheto.
- Compresión GZIP sin pérdida.
- Google Drive y OneDrive.
- Backup aproximado de 24 horas con detección local de cambios.
- Una copia cloud actual por proveedor.
- Estado, correo conectado, permisos, ruta y apertura de ubicación.

## Google Drive

    Mi unidad/CHETO Authenticator/Backups/cheto_native_backup_current.cheto

Scopes: drive.file y drive.appdata.

## OneDrive

    Apps/CHETO Authenticator/cheto_native_backup_current.cheto

Permisos: Files.ReadWrite.AppFolder y User.Read.

## Backup automático

CHETO calcula SHA-256 local antes de tocar cloud. Sin cambios termina sin autenticación ni API. Con cambios comprime, cifra y reemplaza la copia actual.

## Corrección de release candidate

Durante la validación se detectó un crash exclusivo de release minificada porque R8 eliminaba constructores usados por reflexión por WorkManager/Room y ML Kit. Se añadieron reglas R8 específicas y la release candidate posterior fue validada en dispositivo físico.

## Validación

Se verificaron arranque release, recuperación completa desde .cheto, Google Drive, OneDrive, APK firmado, AAB, minificación, CI, tests y lint.

## Seguridad

GitHub no debe contener passwords, keystore release, backups reales, TOTP, tokens ni client secrets.
