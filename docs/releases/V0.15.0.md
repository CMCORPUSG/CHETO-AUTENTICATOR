# CHETO Authenticator 0.15.0

Status: code-complete production-hardening checkpoint before V1.0 RC.

## Included in V0.15

- Versioned Google Drive history with verify, restore, merge and delete actions.
- Recovery-health diagnostics and tests.
- Release/build diagnostics sourced from BuildConfig.
- APK debug and AAB release-candidate generation in CI.
- Explicit Android data-extraction exclusions so OS backup/device transfer cannot copy CHETO vault data.
- CI secret guard for accidental OAuth client secrets and private-key material.
- Release minification/resource shrinking enabled.
- Existing V0.14 security/recovery flows retained and validated.

## External production configuration still required

These items are environment configuration, not source-code features:

- Google OAuth client IDs and signing certificate fingerprints.
- Microsoft Entra/MSAL application registration and Android redirect configuration.
- Final release keystore and provider registration for that release certificate.

No OAuth client secret belongs in the Android APK.

## V0.15 exit criteria

- Local debug build/tests pass.
- GitHub CI unit/lint/instrumentation compile/APK/AAB pipeline passes.
- Physical-device functional flow remains stable.
- No private key/client-secret material is embedded in the application source.

After these checks, development moves to V1.0 RC.
