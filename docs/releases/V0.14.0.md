# CHETO Authenticator 0.14.0

Status: feature-complete checkpoint before V0.15.

## Included

- Versioned Google Drive backup history.
- Verify, restore, merge and delete a specific Drive backup.
- Local and Drive backup integrity verification without restoring.
- Recovery health diagnostics.
- Encrypted recycle bin with retention controls and restore-all.
- Selective encrypted account export.
- Forgot-PIN recovery using a valid encrypted `.cheto` backup.
- Configurable sensitive clipboard timeout.
- Optional reauthentication before revealing hidden TOTP codes.
- Multi-QR Google Authenticator migration tracking.
- Automatic-time warning for TOTP reliability.
- Explicit logo memory/disk cache and initials fallback.
- Debug APK and release AAB candidate in CI.
- Build/version diagnostics from `BuildConfig`.
